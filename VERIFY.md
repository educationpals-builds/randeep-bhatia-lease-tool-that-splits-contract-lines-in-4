# Verify: Lease tool that splits contract lines into separate duties

## What this verification confirms

A stranger can run their own lease duty-splitting setup through the auditor and receive:

1. A finding on the **unowned** check (the deciding check for this build)
2. A demand for a numeric measurement that would confirm the finding

---

## Run the verification

### Step 1: Open /play

Paste a description of a lease tool that splits contract lines into separate duties. Include:

- What the tool is supposed to do
- Who gets hurt when it fails
- Three real lines where it fails (your own "provided that" examples or similar conditional clauses)

### Step 2: Confirm the auditor walks all five checks

The tool should walk through each check conversationally, proposing findings with measurements.

### Step 3: Verify the deciding-check finding surfaces

For this build, the deciding check is **unowned**. The auditor must:

- Surface a finding about ownership of the hinge check
- Name who is accountable when the tool silently fails on a new lease template

### Step 4: Confirm a numeric measurement is demanded

The auditor must demand a specific number for the finding—not a vague "keep an eye on it."

For the builder's audit, the measurement is:

> Watch time-to-notice: how many signed summaries go out before a fused conditional duty is caught by a partner. Priya owns it; if it's more than zero per month, the unowned gap has already caused damage.

The stranger's audit should produce an equivalent: a metric, a danger line, and a named watcher.

## Pass criteria

| Check | Pass |
|-------|------|
| Auditor walks all five checks | ☐ |

| Numeric measurement demanded for unowned | ☐ |
| Danger line stated | ☐ |
